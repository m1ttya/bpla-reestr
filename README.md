# Сайт проекта «БПЛА-Реестр» (лендинг в стиле atlasmotion.com)

Статический сайт: `index.html` + `style.css` + `main.js`. Без сборки и зависимостей (шрифт Inter Tight подгружается с Google Fonts, есть запасной Arial).
Открыть локально: двойной клик по `index.html`. На хостинг: залить три файла в корень.

## Что заменить перед публикацией
1. **Логотипы Фонда и Платформы УТП** — блок `.support` (`<div class="logo-slot">`). Обязательны по договору (Прил. 3 п. 4.2) на главной странице. Брать только официальные файлы от Фонда.
2. **E-mail** `info@example.ru` — 3 места (поиск по файлу).
3. **Название** «БПЛА-Реестр» — рабочее; заменить поиском, если выберете другое.
4. **Ссылки** `/app/demo/` (гостевой вход) и `/privacy` (политика ПДн) — указать реальные адреса.
5. Цифры в макетах интерфейса (ресурс, блоки, хэши) — демонстрационные.

## Анимации
- Загрузчик: кольцо из рисок заполняется, полоска «БАС» растёт, затем кольцо сворачивается и появляются линии сетки.
- Плавная прокрутка (сглаживание lerp), индикатор прогресса справа.
- Заголовки: посимвольный подъём букв из-под маски в случайном порядке.
- Кнопки и меню: текст перелистывается вверх, фон заливается снизу.
- «Каждая деталь — на учёте»: буквы проявляются по мере прокрутки.
- Небо: параллакс фона, дрон парит, наклоняется от скорости прокрутки, вращаются пропеллеры; текст проявляется по словам.
- «Как это работает»: закреплённый блок на 4 шага, 3D-каркас квадрокоптера (canvas, без библиотек) — вращается, реагирует на мышь; шаги: разнесённая сборка с мигающими метками → волны считывателя → дуги ресурса у моторов → орбита блоков блокчейна. Огромное слово меняется с анимацией букв, номер «перебирается».
- Концепция: картинка открывается шторкой, параллакс, текст по словам.
- Интерфейс: слайды макетов панели и PWA, автопереключение, анимированные шкалы ресурса.
- Экосистема: заголовок проявляется из размытия, фон медленно вращается, карточки всплывают.
- CTA: параллакс неба. Курсор оставляет мягкий световой след.
- `prefers-reduced-motion` — анимации отключаются.
